# 🧠 Next.js Project: A Comprehensive Meeting Platform
This project is a fully-featured meeting platform built with Next.js, providing a seamless and intuitive experience for users to schedule, join, and manage meetings. The platform includes features such as meeting setup, video calling, and integration with Clerk for authentication.

## 🚀 Features
* Meeting setup and scheduling
* Video calling with Stream.io
* Integration with Clerk for authentication
* Responsive design with Tailwind CSS
* Global CSS styles for consistency
* Support for multiple meeting types (e.g., one-on-one, group)
* Upcoming meeting list and previous meeting history
* Customizable layout and navigation

## 🛠️ Tech Stack
* Next.js (React framework)
* TypeScript (programming language)
* Tailwind CSS (styling framework)
* Stream.io (video calling API)
* Clerk (authentication API)
* ESLint (code linter)
* PostCSS (CSS post-processor)
* npm (package manager)

## 📦 Installation
To get started with the project, follow these steps:
1. Clone the repository: `git clone https://github.com/your-repo/next-meeting-platform.git`
2. Install dependencies: `npm install`
3. Set up environment variables: `cp .env.example .env` and update the values as needed
4. Start the development server: `npm run dev`

## 💻 Usage
To run the application, use the following commands:
* `npm run dev` (development mode)
* `npm run build` (production build)
* `npm run start` (production mode)
